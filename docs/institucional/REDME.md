# REDME — Guia editorial de memória

A leitura documental, o OCR e a catalogação podem produzir novas observações, mas não autorizam memória automática. Identifique fonte, ID de cliente/processo, documento, ato, data, versão, limitações e qualidade.

No encerramento do trabalho, identifique o que merece memória durável. Faça comparação read-only na R07. Se houver duplicata, não propor outra gravação. Se houver informação mais precisa, preparar antes/depois e apontar o ID anterior, sem declarar revogação.

Para persistir use exclusivamente o mecanismo R06 existente: documento previamente aprovado no registro do servidor; proposta MCP; revisão humana no portal; clique autenticado; readback. A prévia jamais grava. Não confundir simulação com precedente, e não inferir que protocolado significa deferido.

A skill deve ser carregada explicitamente pelo host quando disponível. A presença desta documentação no GitHub não modifica automaticamente o conector já publicado.
